# История для автоматического обучения

Скопируйте сюда `history.csv` в формате образца `docs/synthetic-history.csv`. Docker Compose монтирует папку в `/app/training-data` только для чтения. Изменять файл нужно на хосте. CSV с пользовательскими данными исключены из Git.

При наличии `history.csv` он имеет приоритет над загруженной через интерфейс очередью. Без файла шедулер использует CSV, сохранённый в очереди БД, либо историю активной модели. Изменение файла подхватывается при следующем запуске задания; пересобирать контейнер не нужно.

Расписание по умолчанию: ежедневно 03:00 Europe/Moscow. Настройки — `ML_RETRAIN_*` в `.env.example`. Проверить задание без ожидания можно в ML-лаборатории кнопкой «Проверить и запустить сейчас».
